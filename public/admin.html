Manual payout runbook
  1. Export CSV — the file always contains every pending email claim (filters above only change this view, never the export). USDC claims never enter this file — send the Raw earnings amount from the owner wallet (Exodus) to the claim's address on Base, then Mark paid here.
  2. In Tremendous: Send rewards → campaign AdWait cash-outs → Upload CSV or spreadsheet → upload this file. Use the file name as the order's unique ID so a re-upload can't double-pay. Confirm the order total matches the "billed" figure from the export message.
  3. After the Tremendous order is confirmed, come back here and Mark paid on exactly the claims in that file. Reject anything that fails review — the amount returns to the user's balance automatically.
